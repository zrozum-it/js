# JavaScript – zrozum.it

This repository contains all code examples created for the **zrozum.it** educational series.

The goal of this project is to build a complete JavaScript learning path—from absolute beginner to junior level.

Each folder represents one lesson and contains the code used in the corresponding Instagram post.
