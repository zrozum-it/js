# JS011 — Values

## What is a value?

A value is the information stored inside a variable.

Whenever you assign something to a variable, you are assigning a value.

## Why do values exist?

Programs work with values all the time.

They can read them, compare them, change them, and use them to make decisions.

Without values, variables would be empty boxes with nothing inside.

## How does it work?

Think of a variable as a labeled box.

The value is whatever you put inside that box.

Different variables can store different values.

const age = 25;
