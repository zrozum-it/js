## What is JavaScript?

JavaScript is a programming language.

You can think of it as a way to tell the computer what to do.

We don't speak the language of 0s and 1s, and computers don't understand the language we use every day.

That's why we need a common language to communicate with a computer.

That language is JavaScript.

It allows us to write instructions that a computer can understand and execute.

JavaScript is mainly used to create interactive websites.

It runs primarily in web browsers, but it can also run outside the browser, for example with Node.js.

> We'll come back to that in the next lesson.

---

## Why does JavaScript exist?

Without JavaScript, websites would mostly be static.

Thanks to JavaScript, websites can:

- respond to clicks,
- display new information without reloading the page,
- validate forms,
- and much more.
