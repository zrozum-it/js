# JS003 — What is a Code Editor?

## What is a code editor?

A code editor is a program used to write code.

It helps programmers create, edit and organize their source code in one place.

A code editor does not execute your program.

Its job is to make writing code easier and more comfortable.

---

## Why does it exist?

You could write JavaScript in a simple text editor like Notepad.

However, writing larger programs would quickly become difficult.

A code editor makes programming easier by helping you write, read and organize your code.

---

## What can a code editor do?

Most code editors can:

- highlight code using different colours,
- suggest code while you type,
- organize project files,
- help you spot mistakes.

These features help programmers work faster and make fewer errors.

---

## Popular code editors

Some of the most popular code editors are:

- VS Code
- WebStorm
- Cursor

All of them can be used to write JavaScript.

The best choice depends on your personal preferences and workflow.
