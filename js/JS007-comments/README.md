# JS007 — Comments

## What are comments?

Comments are pieces of text written inside your code.
As projects grow, more people often work on the same code. Comments make it easier for everyone to understand what is happening.

They help people understand the code, but the computer completely ignores them.

Think of them as little notes left for yourself or other developers.

---

## Why do comments exist?

When programs become larger, it becomes harder to remember why something was written.

Comments allow you to explain:

- why something exists,
- leave reminders,
- add useful notes.

---

## How do comments work?

JavaScript supports two types of comments.

Single-line comments and multi-line comments.

The JavaScript engine ignores both.

```js
// This is a single-line comment.

/*
This is
a multi-line comment.
*/
```

## 💭 My thought

It's a little funny that a single-line comment uses two slashes (`//`),
while a multi-line comment starts with `/*` and ends with `*/`.
