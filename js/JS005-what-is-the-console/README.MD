# JS005 — Browser Console

## What is Browser Console?

Browser Console is a tool built into every modern web browser.

It helps developers see messages, warnings and errors while a web page is running.

Most of what JavaScript does happens in the background.

The Browser Console lets us see what is happening.

---

## How to open it?

### Windows / Linux

- F12
- Ctrl + Shift + J

### macOS

- Option + Command + J

You can also:

1. Right-click anywhere on a page.
2. Choose **Inspect**.
3. Open the **Console** tab.
