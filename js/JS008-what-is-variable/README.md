# JS008 — Variables

## What are variables?

A variable is a container for data stored in your computer's memory.

It allows us to save information under a descriptive name, making our code easier to read and understand.

---

## Why do variables exist?

Imagine trying to remember where every piece of information is stored in your computer's memory.

Instead, we give that information a descriptive name.

For example:

- `userName`
- `age`
- `score`

A good variable name makes code easier to understand for both ourselves and other developers.

---

## The box analogy

Think of a storage box.

📦 **The box** → variable

🏷️ **The label** → variable name

🎁 **What's inside** → value

The variable stores the value, while its name helps us find that value later.

---

## How do we create a variable?

In JavaScript, every variable is created using one of three keywords:

- `let`
- `const`
- `var`

We'll learn the differences between them in the next lessons.

---

## What can we do with variables?

There are only three basic things we do with variables:

1. Create a variable.
2. Store or update a value.
3. Read the stored value.

---

## Example

```js
let userName;

userName = "Milena";

console.log(userName);
```

---

## Common mistake

A variable is **not** a value.

Remember:

- 📦 Variable → container
- 🏷️ Variable name → label
- 🎁 Value → what's inside

---

## Remember

A variable stores a value and represents it using a name.
